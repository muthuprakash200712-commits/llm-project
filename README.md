# LLM-Based Document Q&A System

A Retrieval-Augmented Generation (RAG) application that allows users to upload documents and ask questions.

## Features
- PDF/TXT document upload
- Semantic search
- Vector database (FAISS)
- Gemini-powered answers
- Source citation

## Tech Stack
- Python
- Streamlit
- LangChain
- FAISS
- Gemini API
